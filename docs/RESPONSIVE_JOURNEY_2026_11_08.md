Regresi landing memeriksa 320, 390, 620, 768, 960, 1024, 1180, dan 1440 px. Pemeriksaan mencakup lebar tiap panel utama, isi kartu statistik, dan aset gambar yang telah diminta oleh browser. Pemeriksaan visual dan pengujian keyboard terbatas pada alur di atas.

Sebanyak 55 tes backend dan lima suite browser lulus. Semua suite browser yang memakai database terisolasi selesai dengan fingerprint data sandbox yang sama seperti sebelum tes. Build produksi dan pemeriksaan TypeScript lulus. Domain live sempat menampilkan landing dan halaman masuk saat audit. Sebelum push, tautan kembali menuju `/` menghasilkan HTTP 404. Probe HTTP berikutnya juga mendapat 404 untuk `/workspace`, endpoint readiness, dan stylesheet. Bukti ini menunjukkan kegagalan akses pada host publik. Penyebab di konfigurasi hosting masih memerlukan pemeriksaan di sisi server. Uji autentikasi dan penyimpanan data dilakukan di sandbox.
